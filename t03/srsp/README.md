# Алгоритм Евклида: НОД двух чисел

## 1. Таблица тестов

Ожидаемые результаты указаны **до запуска программы** на основании алгоритма Евклида. После запуска результаты сверяются с ожидаемыми.

| № | Ввод `a, b` | Назначение теста | Ожидаемый результат до запуска |
|---:|---|---|---|---|
| 1 | `48, 18` | Обычный случай | `НОД = 6` |
| 2 | `7, 0` | Ноль итераций: условие `b != 0` сразу ложно | `НОД = 7` |
| 3 | `0, 5` | Первое число равно нулю | `НОД = 5` |
| 4 | `21, 14` | Одно число делится на другое | `НОД = 7` |
| 5 | `13, 5` | Взаимно простые числа | `НОД = 1` |
| 6 | `0, 0` | Оба числа равны нулю — запрещённый ввод | Сообщение об ошибке |
| 7 | `-4, 6` | Отрицательное число — запрещённый ввод | Сообщение об ошибке |
| 8 | `abc, 3` | Ввод не является целым числом | Сообщение об ошибке |

Ожидаемые результаты нужно записать до запуска программы. Среда подготовки не содержит .NET SDK, поэтому выполнить настоящий запуск C# здесь не удалось. После локального прогона сравните фактический вывод с ожидаемым.

## 2. Трассировка при `a = 48`, `b = 18`

| Итерация | a до итерации | b до итерации | r = a mod b | a после присваивания | b после присваивания |
|---:|---:|---:|---:|---:|---:|
| 1 | 48 | 18 | 12 | 18 | 12 |
| 2 | 18 | 12 | 6 | 12 | 6 |
| 3 | 12 | 6 | 0 | 6 | 0 |

После третьей итерации условие `b != 0` ложно. Алгоритм выводит `a = 6`.

**Результат:** `НОД = 6`.

## 3. Схема алгоритма

- `gcd.png` — схема алгоритма в PNG.
- `gcd.drawio` — редактируемая схема diagrams.net (draw.io).

## 4. Проект C#

Консольный проект находится в папке `t03/Gcd/`. Запуск из этой папки:

```bash
dotnet run
```

Программа проверяет, что оба значения — целые неотрицательные числа и что они не равны нулю одновременно.
