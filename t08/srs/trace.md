# Трассировка строк в C

## 1. Методы `Trim()` и `Split(';')`

Дана строка:

``` csharp
string s = "  Ахметов Ерлан;85 ";
```

После вызова `s.Trim()` пробелы в начале и конце строки удаляются:

``` text
Ахметов Ерлан;85
```

Затем выполняется `Split(';')`:

``` csharp
string[] parts = s.Trim().Split(';');
```

Полученный массив:

    Индекс Элемент массива       Длина
  -------- ------------------- -------
         0 `"Ахметов Ерлан"`        13
         1 `"85"`                    2

**Ответ:** массив содержит 2 элемента.

## 2. Трассировка `int.TryParse`

Дана строка:

``` csharp
string line = "Иванов Пётр;70;85;x";
string[] parts = line.Split(';');
```

Результат разделения строки:

    Индекс Часть
  -------- -----------------
         0 `"Иванов Пётр"`
         1 `"70"`
         2 `"85"`
         3 `"x"`

Проверка каждой части методом `int.TryParse`:

    Индекс Часть             Результат `TryParse`     Значение `out`
  -------- ----------------- ---------------------- ----------------
         0 `"Иванов Пётр"`   `false`                               0
         1 `"70"`            `true`                               70
         2 `"85"`            `true`                               85
         3 `"x"`             `false`                               0

**Ответ:** `TryParseScores` вернёт `false`, если метод проверяет, что
все части являются целыми числами. Первая часть содержит имя, а
последняя --- символ `x`, поэтому они не преобразуются в `int`.

При неудачном преобразовании `int.TryParse` возвращает `false`, а
переменная `out` получает значение `0`.

## 3. Сравнение `string` и `StringBuilder`

### Вариант со `string`

``` csharp
string s = "";

for (int i = 0; i < 4; i++)
{
    s += i;
}
```

Строки в C# неизменяемые. Поэтому при каждом `s += i` создаётся новая
строка.

       Шаг   `i` Значение `s` после шага   Новая строка
  -------- ----- ------------------------- -------------------
    Начало   --- `""`                      1 (пустая строка)
         1     0 `"0"`                     1
         2     1 `"01"`                    1
         3     2 `"012"`                   1
         4     3 `"0123"`                  1

**Итого:** 5 объектов `string` --- одна начальная пустая строка и четыре
новые строки после сложения.

### Вариант со `StringBuilder`

``` csharp
StringBuilder sb = new StringBuilder();

for (int i = 0; i < 4; i++)
{
    sb.Append(i);
}
```

       Шаг   `i` Содержимое `sb`
  -------- ----- -----------------
    Начало   --- `""`
         1     0 `"0"`
         2     1 `"01"`
         3     2 `"012"`
         4     3 `"0123"`

**Итого:** создаётся один объект `StringBuilder`. Метод `Append()`
изменяет его внутренний буфер, а не создаёт новую строку при каждом
добавлении. При необходимости буфер может расширяться, выделяя
дополнительную память.

## 4. Метод `ToUpper()`

Пример:

``` csharp
string s = "привет";
s.ToUpper();

Console.WriteLine(s);
```

Результат:

``` text
привет
```

**Объяснение:** строки в C# неизменяемые. Метод `ToUpper()` возвращает
новую строку с заглавными буквами, но не меняет исходную строку.
Результат вызова не был сохранён.

Чтобы изменить значение переменной, нужно присвоить ей результат:

``` csharp
s = s.ToUpper();
Console.WriteLine(s);
```

Результат:

``` text
ПРИВЕТ
```

## Вывод

Строки (`string`) в C# неизменяемые: методы вроде `ToUpper()` возвращают
новую строку, а не изменяют старую. При многократном добавлении текста
удобно использовать `StringBuilder`, который изменяет внутренний буфер.
