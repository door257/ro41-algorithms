# Практическая работа: трассировка алгоритмов

## 1. Циклический сдвиг массива влево на одну позицию

Исходный массив:

`a = {4, 1, 7, 3, 9}`

Сначала сохраняем первый элемент `a[0]` в буфер:

`buffer = 4`

Затем сдвигаем остальные элементы на одну позицию влево и записываем буфер в последний элемент массива.

| Шаг | i | Состояние массива после шага |
|---|---:|---|
| Начало | — | `{4, 1, 7, 3, 9}` |
| Сохранение в буфер | — | `{4, 1, 7, 3, 9}` |
| 1 | 0 | `{1, 1, 7, 3, 9}` |
| 2 | 1 | `{1, 7, 7, 3, 9}` |
| 3 | 2 | `{1, 7, 3, 3, 9}` |
| 4 | 3 | `{1, 7, 3, 9, 9}` |
| Запись буфера | — | `{1, 7, 3, 9, 4}` |

**Результат:** `{1, 7, 3, 9, 4}`.

## 2. Разворот массива на месте

Исходный массив:

`a = {4, 1, 7, 3, 9}`

Выполняем обмен элементов `a[i]` и `a[n - 1 - i]`.

Длина массива `n = 5`.

| Шаг | i | Обмен | Состояние массива после шага |
|---|---:|---|---|
| Начало | — | — | `{4, 1, 7, 3, 9}` |
| 1 | 0 | 4 ↔ 9 | `{9, 1, 7, 3, 4}` |
| 2 | 1 | 1 ↔ 3 | `{9, 3, 7, 1, 4}` |

**Результат:** `{9, 3, 7, 1, 4}`.

Выполнено **2 обмена**.

Цикл выполняется только до `n / 2`, потому что при каждом обмене одновременно меняются два элемента: один с начала массива и один с конца. После достижения середины все элементы уже находятся на своих местах.

Для массива нечётной длины центральный элемент остаётся без изменений. Если продолжить цикл дальше, произойдёт повторный обмен уже обработанных элементов.

## 3. Поиск минимального элемента

Ошибочный алгоритм начинается с:

`min = 0`

Проблема заключается в том, что значение `0` используется как начальное значение минимума, хотя минимальное значение массива не обязательно равно нулю или находится в первой позиции.

**Пример массива, на котором алгоритм ошибается:**

`a = {5, 2, 7, 3, 9}`

Если алгоритм сравнивает элементы массива с `min = 0`, он не найдёт значения меньше нуля и ошибочно вернёт `0`, которого нет в массиве.

**Исправление на C#:**

Начальное значение минимума должно быть равно первому элементу массива — `a[0]`.

```csharp
int[] a = { 5, 2, 7, 3, 9 };

int min = a[0];

for (int i = 1; i < a.Length; i++)
{
    if (a[i] < min)
    {
        min = a[i];
    }
}

Console.WriteLine($"Минимальный элемент: {min}");
```

**Результат выполнения:** `Минимальный элемент: 2`.
