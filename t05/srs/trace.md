# Ручная трассировка рекурсивной функции

Дана функция:

```csharp
static int F(int n)
{
    if (n <= 1)
        return 1;

    return n * F(n - 1);
}
```

## 1. Базовый случай и шаг рекурсии

- **Базовый случай:** `n <= 1`. Функция возвращает `1` и не вызывает саму себя.
- **Шаг рекурсии:** если `n > 1`, функция возвращает `n * F(n - 1)`, вызывая себя с аргументом, уменьшенным на единицу.

## 2. Ручная трассировка F(4)

Сначала вызовы идут вниз по стеку: `F(4) → F(3) → F(2) → F(1)`. Затем значения возвращаются в обратном порядке.

| Вызов | Глубина | Возвращает |
|---|---:|---:|
| `F(4)` | 0 | `4 * 6 = 24` |
| `F(3)` | 1 | `3 * 2 = 6` |
| `F(2)` | 2 | `2 * 1 = 2` |
| `F(1)` | 3 | `1` |

Порядок возврата: `F(1) = 1`, затем `F(2) = 2`, `F(3) = 6`, `F(4) = 24`.

**Ответ:** `F(4) = 24`.

## 3. Что произойдёт при F(-1), если условие заменить на n == 1?

Если базовое условие будет таким:

```csharp
if (n == 1)
    return 1;
```

то при вызове `F(-1)` базовый случай не наступит. Функция будет вызывать себя с всё меньшими значениями:

`F(-1) → F(-2) → F(-3) → F(-4) → ...`

Аргумент никогда не станет равен `1`, поэтому рекурсия не завершится. В итоге стек вызовов переполнится. В C# это приведёт к ошибке **StackOverflowException** и аварийному завершению программы.
