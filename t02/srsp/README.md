# Подсчёт цифр и суммы цифр числа

## 1. Псевдокод

```text
НАЧАЛО
    ВЫВЕСТИ "Введите целое неотрицательное число:"
    ВВЕСТИ строку

    ЕСЛИ строка не является целым числом
       ИЛИ число < 0 ТО
        ВЫВЕСТИ "Ошибка: введите целое неотрицательное число."
        КОНЕЦ
    КОНЕЦ ЕСЛИ

    n := число
    сумма := 0
    количество := 0

    ПОВТОРЯТЬ
        цифра := n MOD 10
        сумма := сумма + цифра
        количество := количество + 1
        n := n DIV 10
    ПОКА n > 0

    ВЫВЕСТИ количество, сумма
КОНЕЦ
```

Используется цикл с постусловием (`do-while`): тело выполняется хотя бы один раз. Поэтому для числа `0` алгоритм правильно получает одну цифру и сумму `0`.

## 3. Ручная трассировка

### Ввод `n = 472`

| Итерация | n в начале итерации | Сумма после итерации | Количество после итерации | Условие цикла после итерации (`n > 0`) |
|---:|---:|---:|---:|---|
| 1 | 472 | 2 | 1 | Да (47 > 0) |
| 2 | 47 | 9 | 2 | Да (4 > 0) |
| 3 | 4 | 13 | 3 | Нет (0 > 0 — ложь) |

Результат: **3 цифры, сумма цифр = 13**.

### Ввод `n = 0`

| Итерация | n в начале итерации | Сумма после итерации | Количество после итерации | Условие цикла после итерации (`n > 0`) |
|---:|---:|---:|---:|---|
| 1 | 0 | 0 | 1 | Нет (0 > 0 — ложь) |

Результат: **1 цифра, сумма цифр = 0**.

## 5. Проверка программы

| Ввод | Количество цифр | Сумма цифр |
|---:|---:|---:|
| `472` | 3 | 13 |
| `0` | 1 | 0 |
| `7` | 1 | 7 |
| `1000` | 4 | 1 |

Некорректный ввод, например `abc` или `-12`, должен вывести сообщение об ошибке.
