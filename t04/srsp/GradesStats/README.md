# GradesStats — статистика оценок

Проект для `t04/srsp/GradesStats`.

## Правила
- `0` (`Grades.Stop`) завершает ввод.
- `Grades.Read()` читает целое число; нечисловой ввод возвращает `-1`.
- `Grades.IsValid(g)` принимает оценки от `2` до `5`.
- Неверные значения, включая `-1` и оценки вне диапазона, пропускаются.
- Если введено `0` до любой допустимой оценки, выводится `Оценок нет`.

## Запуск
```bash
dotnet run
```

## Проверочные вводы

1. Ввод: `5`, `4`, `5`, `0`
   Ожидается:
   ```text
   Количество оценок: 3
   Сумма оценок: 14
   Количество пятёрок: 2
   ```

2. Ввод: `0`
   Ожидается:
   ```text
   Оценок нет
   ```

3. Ввод: `3`, `7`, `abc`, `2`, `0`
   Ожидается:
   ```text
   Количество оценок: 2
   Сумма оценок: 5
   Количество пятёрок: 0
   ```

Примечание: если в практической работе 3 использовались другие точные подписи итоговых строк, сохраните их в `PrintStats`; логика и статистические значения здесь соответствуют заданию.
