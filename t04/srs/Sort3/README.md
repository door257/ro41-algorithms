# Sort3

Класс `Order` содержит два метода:

- `Swap(ref int x, ref int y)` — меняет местами значения двух переменных.
- `Sort3(ref int a, ref int b, ref int c)` — сортирует три числа по возрастанию, используя только `Swap`.

Массивы не используются.

## Проверка

Ожидаемый вывод:

```text
3 1 2 -> 1 2 3
1 2 3 -> 1 2 3
3 2 1 -> 1 2 3
2 2 1 -> 1 2 2
5 5 5 -> 5 5 5
```

## Запуск

```bash
dotnet run
```
