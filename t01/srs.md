# Свойства алгоритмов: примеры из жизни колледжа

## 1. Дискретность

**Исходная формулировка с нарушением:**

«Подготовь аудиторию к занятию: расставь парты, проверь компьютер и подготовь доску», — без указания порядка действий.

**Какое свойство нарушено и почему:**

Нарушена дискретность. Алгоритм должен состоять из отдельных последовательных шагов, а не из набора общих требований.

**Исправленная формулировка:**

1. Расставить парты по местам.
2. Проверить работу компьютера.
3. Включить проектор.
4. Подготовить доску к занятию.

## 2. Понятность

**Исходная формулировка с нарушением:**

«Перед занятием выполните инициализацию периферийных устройств».

**Какое свойство нарушено и почему:**

Нарушена понятность. Студент может не знать значение технических терминов и не понять, что именно нужно сделать.

**Исправленная формулировка:**

Перед занятием включите компьютер, подключите мышь и клавиатуру и проверьте их работу.

## 3. Определённость

**Исходная формулировка с нарушением:**

«Сдайте лабораторную работу преподавателю как можно скорее».

**Какое свойство нарушено и почему:**

Нарушена определённость. Не указаны точный срок и конкретный способ сдачи работы, поэтому инструкцию можно понять по-разному.

**Исправленная формулировка:**

Загрузите файл с лабораторной работой в учебную систему до 18:00 дня, указанного в задании.

## 4. Результативность

**Исходная формулировка с нарушением:**

«Продолжайте проверять компьютер до тех пор, пока он не начнёт работать идеально».

**Какое свойство нарушено и почему:**

Нарушена результативность. Не определены конкретный критерий завершения и предел количества проверок. Выполнение инструкции может продолжаться бесконечно.

**Исправленная формулировка:**

1. Включить компьютер.
2. Проверить запуск операционной системы.
3. Открыть текстовый редактор.
4. Если редактор запустился, считать проверку успешной.
5. Если редактор не запустился после трёх попыток, сообщить преподавателю.

## 5. Массовость

**Исходная формулировка с нарушением:**

«Чтобы войти в учебный компьютер, введите пароль `Student123`».

**Какое свойство нарушено и почему:**

Нарушена массовость. Инструкция рассчитана только на один конкретный пароль и не подходит для студентов с другими учётными записями.

**Исправленная формулировка:**

1. Введите свой логин в поле «Логин».
2. Введите пароль от своей учётной записи в поле «Пароль».
3. Нажмите кнопку «Войти».
4. Если данные верны, откроется рабочий стол.

Эта инструкция подходит всем студентам, у которых есть учётная запись.

## Вывод

Алгоритм должен состоять из отдельных шагов, быть понятным исполнителю, однозначным, приводить к результату за конечное число действий и подходить для целого класса однотипных задач. Соблюдение этих свойств делает инструкции колледжа точными и удобными для выполнения.
