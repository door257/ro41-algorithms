# Перевод секунд в часы, минуты и секунды

## 1. Словесная запись алгоритма

1. Начать выполнение программы.
2. Запросить у пользователя количество секунд.
3. Считать введённое значение.
4. Проверить, удалось ли преобразовать ввод в целое число типа `long` и является ли число неотрицательным.
5. Если ввод некорректен, вывести сообщение об ошибке и завершить программу.
6. Вычислить количество часов: `часы = секунды / 3600`.
7. Вычислить количество минут из остатка: `минуты = (секунды % 3600) / 60`.
8. Вычислить оставшиеся секунды: `остаток = секунды % 60`.
9. Вывести часы, минуты и секунды.
10. Завершить программу.

## 2. Псевдокод

```text
НАЧАЛО
    ВЫВЕСТИ "Введите количество секунд:"
    ВВЕСТИ строку

    ЕСЛИ строка не преобразуется в целое число
       ИЛИ число < 0 ТО
        ВЫВЕСТИ "Ошибка: введите целое неотрицательное число."
        КОНЕЦ
    КОНЕЦ ЕСЛИ

    часы = число DIV 3600
    минуты = (число MOD 3600) DIV 60
    остаток = число MOD 60

    ВЫВЕСТИ часы, минуты, остаток
КОНЕЦ
```

`DIV` означает целочисленное деление, `MOD` — остаток от деления.

## 5. Проверка программы

| Ввод (секунды) | Часы | Минуты | Секунды | Результат |
|---:|---:|---:|---:|---|
| 3725 | 1 | 2 | 5 | `1 ч 2 мин 5 с` |
| 59 | 0 | 0 | 59 | `0 ч 0 мин 59 с` |
| 86399 | 23 | 59 | 59 | `23 ч 59 мин 59 с` |
| 0 | 0 | 0 | 0 | `0 ч 0 мин 0 с` |

Дополнительно: ввод `abc` и `-5` должен вывести сообщение об ошибке, не завершаясь аварийно.
