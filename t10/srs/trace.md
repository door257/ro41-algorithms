# Трассировка алгоритмов — t10

## 1. Сортировка выбором

Исходный массив: `a = {5, 2, 9, 1, 7}`.

На каждом проходе `i` ищем минимум в неотсортированной части массива `a[i..n-1]`, затем меняем его местами с `a[i]`. Число сравнений на проходе равно `n - i - 1`.

| Проход `i` | Индекс минимума | Массив после обмена | Сравнений на проходе |
|---:|---:|---|---:|
| 0 | 3 | `{1, 2, 9, 5, 7}` | 4 |
| 1 | 1 | `{1, 2, 9, 5, 7}` | 3 |
| 2 | 3 | `{1, 2, 5, 9, 7}` | 2 |
| 3 | 4 | `{1, 2, 5, 7, 9}` | 1 |

На проходе `i = 1` минимум уже стоит на нужном месте, поэтому обмен не меняет массив.

**Общее число сравнений:** `4 + 3 + 2 + 1 = 10`.

Результат: `{1, 2, 5, 7, 9}`.

## 2. Сортировка вставками

Исходный массив: `a = {4, 3, 2, 1}`.

На каждом шаге сохраняем `key = a[i]` и сдвигаем вправо все предыдущие элементы, которые больше `key`. Затем вставляем `key` в освободившуюся позицию.

| `i` | `key` | Число сдвигов | Массив после вставки |
|---:|---:|---:|---|
| 1 | 3 | 1 | `{3, 4, 2, 1}` |
| 2 | 2 | 2 | `{2, 3, 4, 1}` |
| 3 | 1 | 3 | `{1, 2, 3, 4}` |

**Всего сдвигов:** `1 + 2 + 3 = 6`.

**Сравнения на уже отсортированном массиве из 4 элементов:** `3`. На каждом из трёх проходов (`i = 1, 2, 3`) выполняется одно сравнение `a[j] > key`, которое сразу оказывается ложным. Здесь считаются сравнения элементов массива с `key`, без учёта проверок границы `j >= 0`.

## 3. Бинарный поиск

Исходный отсортированный массив: `a = {1, 3, 5, 7, 9, 11, 13}`.

Для обычного бинарного поиска используем включительные границы: сначала `lo = 0`, `hi = 6`; пока `lo <= hi`, вычисляем `mid = (lo + hi) / 2`.

### Поиск `x = 7`

| Шаг | `lo` | `hi` | `mid` | `a[mid]` | Решение |
|---:|---:|---:|---:|---:|---|
| 1 | 0 | 6 | 3 | 7 | `a[mid] == x`: элемент найден, поиск завершён |

Индекс найденного элемента: `3`.

### Поиск `x = 6`

| Шаг | `lo` | `hi` | `mid` | `a[mid]` | Решение |
|---:|---:|---:|---:|---:|---|
| 1 | 0 | 6 | 3 | 7 | `7 > 6`: ищем слева, `hi = 2` |
| 2 | 0 | 2 | 1 | 3 | `3 < 6`: ищем справа, `lo = 2` |
| 3 | 2 | 2 | 2 | 5 | `5 < 6`: ищем справа, `lo = 3` |

Теперь `lo = 3`, `hi = 2`, то есть `lo > hi`. Поиск завершается: элемента `6` в массиве нет.

**Значение `LowerBound(6)`:** `3`. Это индекс первого элемента, который не меньше `6` (элемента `7`), то есть позиция, куда можно вставить `6`, сохранив порядок массива. Если считать позиции с нуля, результат — `3`.
